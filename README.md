# 119 사고현장 확인 (1단계 시험판)

119 상황전파 메시지를 붙여넣으면 사고지점의 **지도와 로드뷰를 한 화면에** 띄우고, 로드뷰 촬영지점이 사고지점에서 얼마나 떨어졌는지 표시하는 휴대폰 웹앱(PWA)입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체(화면·메시지 분석·지도 연결). 이 파일만 고치면 대부분 반영 |
| `manifest.json` | 홈 화면 설치 정보, 안드로이드 공유 받기(share_target) |
| `service-worker.js` | 설치·업데이트 처리. 캐시 접두어 `ndms-onestop-`, 저장 키 접두어 `ndms-onestop.` (법ON `lawon-`, 오늘의안전 `onul-safety-`, 노무길잡이 `nomugil-`와 겹치지 않게) |
| `icon-*.png` | 앱 아이콘 |
| `tests/` | 메시지 분석·캐시 삭제 범위·키 자리표시 시험(배포 때 자동 실행), 화면 흐름 시험(`python3 tests/ui_test.py`, 가짜 카카오 지도, 수동) |
| `.github/workflows/deploy.yml` | 시험 후 배포, 배포 때 카카오 키 넣기 |

## 처음 설정

### 1. 저장소에 올리기
1. 새 저장소 `ndms-onestop` 생성 → 압축을 푼 폴더 **안의 파일들**을 저장소 맨 위에 올림
2. **`.github/workflows/deploy.yml`은 따로 만들기**: 점(.)으로 시작하는 폴더는 끌어다 올릴 때 빠지는 경우가 많음
   - 저장소 첫 화면 → Add file → Create new file → 파일 이름 칸에 `.github/workflows/deploy.yml` 입력 → 내용 붙여넣기 → Commit

### 2. 카카오 키를 비밀값으로 넣기
1. 저장소 Settings → Secrets and variables → Actions → **New repository secret**
2. Name: `KAKAO_JS_KEY` / Secret: 카카오 **JavaScript 키**(영문·숫자 32자, REST API 키 아님)
3. 저장소에는 키가 들어가지 않음. 배포할 때만 `index.html`의 자리표시 `__KAKAO_JS_KEY__`가 키로 바뀜
   - 배포된 화면 소스에는 키가 보임(카카오 지도는 브라우저에서 키를 쓰는 구조). 보호는 카카오의 도메인 제한으로 함
   - 저장소의 `index.html`에 실제 키를 직접 적지 말 것(시험 단계에서 막힘)

### 3. GitHub Pages를 'Actions 배포'로 켜기
1. Settings → Pages → Build and deployment → Source: **GitHub Actions** (Deploy from a branch 아님)
2. Actions 탭에서 '시험 후 배포'가 초록색이면 완료 → `https://yeonskimm.github.io/ndms-onestop/`
3. 시험(메시지 분석, 캐시 삭제 범위, 키 자리표시) 중 하나라도 실패하면 배포하지 않고 기존 화면 유지

### 4. 카카오 Developers 설정
1. 앱(NDMS-OneStop) → 카카오맵 사용 설정 **ON**
2. [앱] → [플랫폼 키] → [JavaScript 키] → **JavaScript SDK 도메인**에 `https://yeonskimm.github.io` 하나만 등록
   - PC 시험용 `http://localhost`를 넣었다면 시험 후 바로 삭제(남아 있으면 누구나 자기 PC에서 이 키를 쓸 수 있음)
3. 결제 수단은 등록하지 않음(사용량 초과 시 막히기만 하고 과금 없음) 🔵
4. 키를 재발급하면 2번의 비밀값만 바꾸고 Actions에서 다시 배포(Run workflow)

- 개인 키를 앱 [설정]에 넣으면 그 휴대폰에서는 개인 키가 우선함

### 5. 홈 화면에 설치
- 안드로이드: 앱을 열면 나오는 [설치] 버튼, 또는 Chrome 메뉴 → 홈 화면에 추가
- 아이폰: Safari로 열고 공유 → 홈 화면에 추가

## 메시지 넣는 방법

| 방법 | 안드로이드 | 아이폰 |
|---|---|---|
| 복사 후 [복사한 메시지 붙여넣고 확인] | ○ | ○ (붙여넣기 허용 팝업 1회) |
| 카카오톡 메시지 길게 누름 → 공유 → 앱 선택 | ○ (설치한 경우) | × |
| 단축어(아래) | - | ○ |

### 아이폰 단축어 만들기(선택)
1. 단축어 앱 → 새 단축어 → 공유 시트에 보기 켜기, 받는 항목 '텍스트'
2. 동작 추가: **URL 인코딩**(입력: 단축어 입력)
3. 동작 추가: **텍스트** → `https://yeonskimm.github.io/ndms-onestop/?t=` 뒤에 'URL 인코딩된 텍스트' 넣기
4. 동작 추가: **URL 열기**
5. 카카오톡 메시지 길게 누름 → 공유 → 이 단축어

※ 이렇게 열면 홈 화면 앱이 아니라 Safari 창으로 열립니다. 키는 Safari 쪽에도 한 번 넣어야 합니다.

## 1단계에 들어간 것

- 119 메시지 분석: 여러 건 한꺼번에, 같은 사고 1보·2보 묶기, 괄호 안 높이·의식·연령대 추출, 교통사고 구분
- 주소 → 좌표: 주소검색 → 장소검색 → 번지 빼고 검색 순서. 정확도가 낮으면 화면에 표시
- 지도·로드뷰 고정 분할 화면(페이지 스크롤 없음), 300m 안 가장 가까운 로드뷰, 사고지점 쪽으로 자동 회전
- 사고지점–촬영지점 거리: 50m 이내 초록 / 100m 이내 노랑 / 그 이상 빨강
- 지도를 누르면 그 근처 로드뷰로 이동
- 사업장명 종류별 처리: 업체명 / 건물명(관리사무소 검색) / 건설현장 / 파악불가(주소로 시험 검색). 모두 '후보'로만 표시
- 관할 소방: 대구·경북 공식 관할표(대구소방안전본부 2025.12.31, 경북 시행규칙 별표2 2026.8.3)로 관할 안전센터·지역대·소방서를 정하고, 그 이름으로 카카오 등록 번호를 찾음. 가까운 안전센터 3곳도 참고로 표시
  - 관할표 고칠 곳: `index.html`의 `FIRE-START` ~ `FIRE-END` 부분(규칙 형식은 그 위 주석 참고), 고친 뒤 `node tests/fire_test.js`
- 보고용 내용 복사(미확인 항목 🔵 표시, 관할 소방 포함)
- 뒤로가기: 안드로이드 뒤로 버튼 = 앱 안 '‹ 뒤로', 첫 화면에서 '한 번 더 누르면 종료'. 아이폰은 앱 안 '‹ 뒤로'
